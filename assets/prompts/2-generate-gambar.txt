# Prompt Generate Referensi Gambar

Buka **https://gemini.google.com** → New Chat → tempel prompt di bawah.

> ⚠️ Gemini sering render teks panjang dengan tidak akurat di gambar. **Itu normal.**
> Yang penting: layout, warna, proporsi, dan bentuk. Teks asli tetap pakai font dari kode.

---

## Gambar 1 — HUD (`hud-mockup.png`)

```
Buat mockup UI untuk HUD game snake, gaya "premium mobile game".

Susunan:
- Baris atas: 3 stat card glassmorphism (SKOR, PANJANG, BEST) dengan nilai besar
- Bawahnya: 3 effect chip (perisai biru, kura-kura kuning, "2x" ungu) dengan progress bar yang sedang menyusut
- Ujung kanan baris atas: 2 icon round (speaker, pause)

Background: #030712 gelap. Accent: emerald #10b981. Font: Inter/Sora.
Style: frosted glass card, border tipis, subtle glow, soft shadow.
Ukuran: 1440 x 260px, landscape, flat design, high fidelity UI mockup, clean modern.
```
